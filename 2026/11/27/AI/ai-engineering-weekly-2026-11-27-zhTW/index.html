前沿 AI 工程週報｜2026-11-27

Posted on 2026-11-27 In AI Views: Word count in article: 961 Reading time ≈ 3 mins.

本週最值得注意的是：前沿模型的兩種進步指標出現落差、兩家實驗室先後發布會重複執行部分層的 Transformer，以及新的 agent 評測結果。

>> [English version] <<

11/24｜METR：預訓練損失降得更快，外部評測沒有同步加速

METR 分析了 OpenAI 公開的 13 個基礎模型數據。固定使用取自 OpenAI 自家程式碼庫的測試集時，2026 年初以來的 log-perplexity（對數困惑度）下降速度，約是 2022 至 2025 年的 7 倍。但 Epoch 的 ECI 等外部評測，並未出現相近的加速。這是外部研究團隊對單一實驗室數據的分析，不代表模型能力也進步了七倍。METR 分析

11/20–23｜模型架構：兩家實驗室發布 Looped Transformer

Thinking Machines Lab 發布開放權重的 Inkling 2 Mini，共 264 億個參數，每生成一個 token 會把中間層跑三遍，並另外提供可調整循環次數的研究版。Z.ai 的 GLM-5.4 則是自家首款採用這種架構的旗艦模型，已在 GLM Coding Plan 上線。兩者都靠重複使用同一組層來增加內部運算，不必為每一遍新增一組權重。這證明這種架構已出現在兩種不同的發布情境，不代表一定更快或更準；Z.ai 也指出 GLM-5.4 有時會推理太久。Thinking Machines Lab · Z.ai 公告 · ZCode 更新紀錄

11/23｜Skills：完整達標率有提升，但多數任務仍未達成所有條件

SkillForgeBench v3 報告了 842 個沙盒任務的結果。Opus 4.8 有 Skill 時，40.9% 的任務符合全部輸出要求；沒有 Skill 時是 21.7%。有 Skill 時，逐項計分的平均分數是 85.7%。逐項拿高分，不等於同一項任務的所有條件都達標。數字來自評測作者，而任務本身就是圍繞 Skills 設計，不能把增幅直接套用到其他工作。SkillForgeBench v3 表 2

11/24｜Delegent：子 agent 降低費用，但程式任務耗時增加

作者在 50 題 DeepSWE 上比較兩種配置：全用 GPT-6.1 Sol，以及用指令引導 Sol 搭配 Qwen3.8-27B 子 agent。兩組都解出 29／50 題。前沿模型的 API 費用從每題 US$2.11 降到 $0.70（把子 agent 的預估 API 費用算進去是 $0.81），但中位耗時從 25 分鐘增至 38 分鐘。兩組原本就都有子 agent，這是兩種委派方式的比較，不是單 agent 對多 agent。Delegent 預印本

11/25｜Qwen4-Max：預覽定價結束

阿里雲停用 qwen4-max-preview。官方更新紀錄指出，舊的模型 ID 會自動轉到標準版，並按標準價格計費。國際區公開牌價為每百萬 token 輸入 US$1.50、輸出 US$4.50。這是本月稍早推出的模型在存取與計費上的變動，不是本週新模型發布。更新紀錄 · 模型與定價

其他值得一看

  • 11/23｜Qwen-Audio-3.1-Live。 阿里雲推出全雙工語音模型，應用程式或背景模型在處理任務時，語音模型仍能繼續和使用者對話。API 文件
  • 11/24｜ERNIE 5.5 Flash Preview。 百度釋出仍在後訓練階段的預覽權重，支援 100 萬 token 的上下文；Apache 2.0 授權只適用於這次的預覽權重，不適用於先前的基礎模型。模型卡
  • 11/25｜Hurdle。 Together AI 開源可針對 API、Skills 和文件評測 agent 的工具；託管模式支援明確設定 API 請求規則，本機模式無法攔截 API 流量。發布公告
